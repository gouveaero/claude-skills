# claude-skills

Personal skills for [Claude Code](https://claude.ai/code) — marketing, CRO, SEO, outbound, ads, and ops workflows.

Skills are structured guides that instruct Claude on how to approach specific tasks. Each folder is a skill with a `SKILL.md` entry point.

## Installation

```bash
# Clone directly into the Claude Code skills directory
git clone https://github.com/gouveaero/claude-skills.git ~/.claude/skills
```

## Updating

```bash
cd ~/.claude/skills && git pull
```

## Usage

Once installed, skills activate automatically when Claude detects a relevant task. You can also invoke them explicitly in Claude Code via the `Skill` tool.
