# Roteiro Council — verdict / scorecard template (chairman output)

The chairman gets the framed context + all 9 de-anonymized advisor outputs + all 9 peer reviews, reconciles conflicts with the priority ladder (**Accurate > Clear > Specific > Voiced > Stylish**), and produces this. Present it in chat, scannable, no raw transcripts unless asked, no HTML/report file.

The **weakest-element rewrite** defaults to the dimension with the worst verdict (usually the hook → rewrite it 3 ways). If Anti-slop or Voice/Brand is the FATAL one, rewrite that element instead. The council rewrites only the ONE weakest element — full rewrites route to a generator.

## Scoring guidance
- **FATAL** = this alone will sink the post (kill-on-publish). **WEAK** = real drag, fixable. **OK** = ships as is.
- Notas: 1-2 = FATAL, 3 = WEAK, 4-5 = OK. Keep them honest — a calibrated "mostly OK, one WEAK" verdict is a valid and useful result; do not manufacture FATALs.
- The generalist line is not scored — it's qualitative (fatal flaw / blind spot / opportunity).
