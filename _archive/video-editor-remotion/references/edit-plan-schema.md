# `edit_plan.json` schema (Remotion flavor)

Source of truth for the entire reel. Generated by `plan_edit.py`, consumed by
`build_remotion.py` (which writes a copy to `<remotion>/src/edit_plan.json`,
imported by `Reel.tsx`).

You can hand-edit this file and the Remotion Studio will hot-reload — but
remember any future `plan_edit.py` run will overwrite it.

## Top-level fields

```jsonc
{
  "name": "agiota-reel",
  "duration_target_seconds": 30,
  "aspect": "9:16",
  "fps": 30,
  "resolution": [1080, 1920],

  "v1_main": [...],           // primary video track (cuts)
  "transitions": [...],       // optional transitions between cuts
  "subtitle_track": [...],    // kinetic captions
  "overlays_v2": [...],       // big-stat moments
  "audio_sync_beats": [12.4, 18.0],   // optional emphasis timestamps
  "color_correction": { "css_filter": "saturate(0.92) contrast(1.05)" },
  "render_preset": "h264_master_q18"
}
```

## v1_main (cuts)

Each entry is one cut on the main video track. They concat in order; gaps are
not allowed.

```jsonc
{
  "clip": "01_intro.mp4",         // must exist in remotion/public/clips/
  "source_in": 1.20,              // seconds inside the source clip
  "source_out": 3.45,             // seconds inside the source clip
  "timeline_start": 0.0,          // optional; computed from cumulative durations
  "rationale": "best take of intro hook, clean cut at silence"
}
```

`durationInFrames` for the Sequence is `Math.round((source_out - source_in) * fps)`.

## transitions

Optional. Each entry inserts a transition AFTER cut at `after_cut_index`.
Transition duration is OVERLAPPING — both clips render simultaneously during
the transition, so it shortens total runtime by `duration_frames`.

```jsonc
{
  "after_cut_index": 2,            // 0-based — applies after cuts[2]
  "type": "fade",                  // fade | slide_up | wipe | none
  "duration_frames": 6             // 4-12 typical; 0 = hard cut
}
```

Default if omitted: hard cuts (`type: "none"`) between every cut.

## subtitle_track

Word-level kinetic captions. 1–4 words each, UPPERCASE.

```jsonc
{
  "text": "AGIOTA",
  "start": 1.20,                  // seconds in final timeline
  "end": 1.92,
  "style": "highlight_accent",    // highlight_accent | highlight_box | minimal
  "emphasis": "emphasis"          // keyword | emphasis | normal — overrides classifyWord
}
```

Captions render as overlays over the main video, positioned by KineticCaption.

## overlays_v2 (stats)

Big-number moments. The text is held centered, animated with spring entry +
fade exit.

```jsonc
{
  "text": "37%",
  "subtext": "DAS DIVIDAS DO PAÍS",
  "start": 8.5,
  "end": 11.0
}
```

## audio_sync_beats

Free-form list of timestamps (seconds) where you want extra visual punch
later. The MVP doesn't auto-consume these — they're metadata for human
iteration ("at 12.4s the music hits, sync a flash"). Future versions can
animate captions/zooms tied to these.

## color_correction

CSS filter string applied to every VideoCut. Keep subtle — over-saturation
turns skin tones plasticky.

```jsonc
{ "css_filter": "saturate(0.92) contrast(1.05) brightness(1.04) hue-rotate(-3deg)" }
```

Common presets:
- Warm + crispy: `saturate(0.92) contrast(1.05) brightness(1.04)`
- Cool/cinematic: `saturate(0.85) contrast(1.1) hue-rotate(8deg)`
- Punchy social: `saturate(1.15) contrast(1.12)`
- Faded film: `saturate(0.7) contrast(0.95) brightness(1.06) sepia(0.08)`

## Forbidden / common mistakes

- `timeline_start` gaps — Remotion's `<TransitionSeries>` concatenates,
  there's no way to leave a gap inside it (you'd need a separate placeholder).
- Captions extending past final video duration — they'll render but Studio
  shows a warning. Trim subtitle ends.
- `clip` name with spaces — it's a URL path; replace with underscores or quote
  carefully. `setup_project.py` preserves filenames as-is, so name your raw
  clips without spaces.
- Forgetting the file is regenerated — when you `plan_edit.py` again it
  overwrites. Save manual tweaks as a backup if iterating.
